# E2B Sandbox

Cloud sandbox for [Inspect AI](https://inspect.aisi.org.uk/) using [E2B](https://e2b.dev/).

For setup, configuration, and usage, see the [E2B provider page](https://meridianlabs-ai.github.io/inspect_sandboxes/e2b.html) on the [`inspect_sandboxes` documentation site](https://meridianlabs-ai.github.io/inspect_sandboxes/).
